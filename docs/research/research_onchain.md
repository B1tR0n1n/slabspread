### 1.4 Is FMV / buyback / instant-sell price exposed via an API?

- **Yes, undocumented but live**: `GET https://api.courtyard.io/orderbook/assets/{proofOfIntegrity}` returns `asset.fmv_estimate_usd` (e.g. 732), `minimum_bid_threshold` (e.g. 367 ≈ 50% of FMV), `offer_data` (buy-side bids with USDC amounts), `orderbook_bids`, `orderbook_asks`/`listing_data`, plus attributes. VERIFIED-BY-FETCH (3rd-party fixture + probe table dated 2026-08-01): https://raw.githubusercontent.com/Evan-Kim2028/live-gacha-listings-fetcher/main/fixtures/courtyard-orderbook-asset.json and https://raw.githubusercontent.com/Evan-Kim2028/live-gacha-listings-fetcher/main/src/providers/courtyard.ts. The 90%-of-FMV instant buyback price is therefore derivable (0.9 × `fmv_estimate_usd`) but the buyback quote itself is not a documented public field. Buyback is 90% FMV cards / 95% watches, funded to the user's Courtyard USDC balance — SEARCH-SNIPPET-ONLY: https://courtyard.io/about, https://play.google.com/store/apps/details?id=io.courtyard.app, https://www.facebook.com/courtyard.io/videos/unlock-90-instant-buyback-on-every-pull/1508398863843672/
- Other live unauthenticated endpoints (same probe): `GET /orderbook/config`, `GET /index/asset/{id}`, `GET /index/token/polygon/{contract}/{tokenIdHex}/metadata.json`, `GET /configs/providers/config.json`. **No bulk bids/offers endpoint** (`/orderbook/bids` → 404). Listings are served by **Algolia** (app `Y8TL3M06QA`, public search key `3b3ed18284ca0baee9a496aea5f093d6`, index `marketplace_prod_recently_listed`, 5,000-hit deep-pagination ceiling). ### 2.2 How sales and buybacks appear on-chain

- **Marketplace sales**: executed by program `CcmRKT…` instructions `buy_nft / buy_pnft / buy_core / buy_cnft`, `accept_offer_for_*`, `list_*_for_sale`, `create_listing_*`, `make_offer_*`, with PDAs `market` (usdc_mint, fee_bps, treasury, owner), `listing` (asset, seller, price, collection), `offer` (asset, buyer, price), `user_escrow`. **No Anchor events in the IDL** — sale detection must decode instruction data + USDC token transfers (seller_usdc_account, treasury_token_account) from tx logs. VERIFIED-BY-FETCH (3rd-party IDL dump). Marketplace is USDC-denominated; official docs describe a build → sign → `POST /marketplace/broadcast` flow — SEARCH-SNIPPET-ONLY https://docs.collectorcrypt.com/marketplace/api. Cards also trade on Magic Eden (symbol `collector_crypt`, ME's own M2/MMM programs) and, since 2026-08-31, OpenSea OS2 Solana — SEARCH-SNIPPET-ONLY (Metaplex/OpenSea news snippets).
- **Gacha pack purchases**: *no bespoke program*; a purchase tx = Memo instruction (`<slug>-<uuid>`, memo requires signature of `GachaNgy…`) + plain SPL `TransferChecked` of USDC from player ATA → treasury ATA `D9CEog…`; the tx is pre-signed by CC's gacha authority, so it can only be built via `POST /api/generatePack`. VERIFIED-BY-FETCH (3rd-party): Tangem README; https://raw.githubusercontent.com/rhcollect/Collect/main/backend/src/cc/types.ts and docs/00-PROJECT-BRIEF.md. DefiLlama counts all non-team USDC inflows to the gacha sinks as pack sales.
- **Gacha buybacks**: legacy path = standing Token-Metadata transfer delegate on the pNFT; CC backend builds/co-signs a tx that moves the NFT back to CC ("rotating prize wallets") and refunds USDC from the gacha sink to the user. New atomic path (Core assets have `PermanentTransferDelegate`/`PermanentBurnDelegate` = CC). DefiLlama identifies buybacks as **USDC outflows from the gacha sink addresses to non-team addresses**. VERIFIED-BY-FETCH (3rd-party): Tangem README + DefiLlama adapter. Buyback = `instantBuyback%` (85/90/93 by machine tier) × insured value, capped at 40,000 USDC, 72-hour window after reveal, follows the card not the wallet. VERIFIED-BY-FETCH (3rd-party): Tangem README, rhcollect types.ts, Starchild skill.
- Indexed "real-time value sourced from eBay and ALT" backs the buyback quote per Solana Compass — SEARCH-SNIPPET-ONLY https://solanacompass.com/learn/Lightspeed/collector-crypt-onchain-capital-markets-on-solana-tuomas-holmberg ; the API exposes it as `insuredValue`.
