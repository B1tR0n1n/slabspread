# Fixtures

Tests never make live calls (plan §1). Everything here is replayable input.

## `real/` — captured responses
Recorded by third-party integrators and fetched from their public GitHub repos during Phase 0
(the build environment could not reach the platforms directly). Provenance per file:

| File | Shape | Origin |
|---|---|---|
| `courtyard/metadata_psa66499345.json` | Courtyard tokenURI `metadata.json` | ismellike/nft-gacha (captured 2026) |
| `courtyard/orderbook_asset_psa91000615.json` | `GET api.courtyard.io/orderbook/assets/{poi}` | Evan-Kim2028/live-gacha-listings-fetcher, probe 2026-08-01 |
| `collectorcrypt/marketplace_page.json` | `GET api.collectorcrypt.com/marketplace` page | same repo (third row is the integrator's synthetic no-mint case) |
| `phygitals/marketplace_listings.json` | `GET api.phygitals.com/api/marketplace/marketplace-listings` | same repo |

Note on Collector Crypt: in this capture `serial` is the **card number** and no `gradingID` (cert) field is
present. Phase 0 evidence says `gradingID` exists on other rows/endpoints; the normalizer accepts it when present.

## `corpus/` — labeled identity corpus (synthetic, schema-faithful)
Fifty slab records that follow the `real/` shapes exactly, generated by `tests/gen_corpus.py` with a fixed seed,
plus `truth.json` naming which records are the same slab (cert) and the same card (canonical key).
It exists so the Phase 1 exit test (≥95% cert identity, fuzzy candidates for the rest) is runnable offline.
**It is not evidence about the platforms.** Replace with real captures as soon as a platform host is reachable;
the test harness reads any file in `corpus/` with the same layout.

## `rpc/` — JSON-RPC responses (synthetic, spec-shaped)
Built by `tests/gen_rpc_fixtures.py`. Polygon log `data` is produced by the same ABI encoders the
decoders are tested against; Solana transactions follow the documented `jsonParsed` layout. The
Courtyard trade reuses the real tx hash / amount from Phase 0 (`0x71f546e3…`, 150 USDC) so the
shape can be diffed against the real receipt later. **Not evidence about the platforms.**
